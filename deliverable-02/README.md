# Deliverable 02

## Run

In order to run the kernel without analysers go to this directory and execute
```
./run.sh
```

This will set up the environment with all the matrices and submit the jobs. The matrices se-up may require a long time.

## Monitor

In order to run the kernel with analysers go to this directory and execute either:
```
./ncu.sh
```

or

```
./nsys.sh
```

This will set up the environment with all the matrices and submit the jobs. The matrices se-up may require a long time.
